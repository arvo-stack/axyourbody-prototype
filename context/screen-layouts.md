# 화면 레이아웃 명세

대상: 과업 3 흐름의 일곱 화면 + 갈림길 네 화면 + 상태 화면 네 개
기준 폭 360pt · 세로 스크롤 · 하단 탭 고정 (탭이 있는 화면만)
원본: Figma `04-wireframe 과업3` · 근거: context/screen-flow.md, context/service-structure.md

---

## 공통 규칙

| 항목 | 규칙 |
|---|---|
| 세로 구조 | 상태바 → 상단(날짜·화면 이름) → 본문 → 하단 탭 |
| 상단 | 메뉴 화면은 날짜(작게·회색) + 화면 이름. 하위 화면은 뒤로(‹ 이전 화면 이름) + 화면 이름 |
| 좌우 여백 | 20pt 고정 |
| 블록 간격 | 12pt (본문 블록 사이) |
| 주 버튼 | 한 화면에 하나만. 폭 100%, 진한 초록, 높이 48pt 이상 |
| 보조 버튼 | 흰 바탕 + 테두리. 주 버튼 아래에 둠 |
| 보조 링크 | 밑줄 텍스트. 「오늘은 못 가요」「다른 코스 보기」처럼 빠져나가는 길 |
| 오늘 할 운동 | 한 화면에 코스 **하나만** 보여 줌. 여러 개를 나열해 고르게 하지 않음 |
| 추천 이유 | 「이런 이유로 추천드려요」 블록. 오늘 화면과 갈림길 A·B·C의 코스·계획 카드 안에만 둠 |
| 조건부 안내 | 점선 테두리 회색 블록(추운 날·마감 안내 등). 조건이 맞을 때만 나타남 |
| 탭바 | 네 칸 고정: 오늘 · 기록 · 변화 · 나. 지금 메뉴만 굵은 초록 |
| 빈 칸 표현 | 점선·회색과 「비어 있어도 괜찮아요」. 빨간색·느낌표·「실패」를 쓰지 않음 |
| 숫자 표기 | 단위를 붙임 (분, 회, kg, °C) |

## 1. 퇴실 알림

```
┌───────────────────────────────┐
│ 17:58                         │  상태바
│                               │
│            17:58              │  잠금화면 시계
│       11월 27일 목요일          │
│ ┌───────────────────────────┐ │
│ │ AX YOUR BODY · 지금         │ │  알림 카드
│ │ 오늘 할 운동: 30분 헬스 코스  │ │  제목 1줄
│ │ 18:10에 출발하면 19:00 전에   │ │  설명 1줄
│ │ [ 시작하기 ] [ 오늘은 못 가요 ]│ │  같은 크기 두 버튼
│ └───────────────────────────┘ │
│ ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐ │
│   추운 날에는 "실내 코스"로 알림   │  조건부 메모
│ └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘ │
└───────────────────────────────┘
```

| 영역 | 들어가는 것 | 상태에 따른 변화 |
|---|---|---|
| 알림 카드 | 오늘 할 코스 이름, 출발 시각과 끝나는 시각 | 추운 날은 「오늘 할 운동: 20분 실내 코스」로 바뀜 |
| 두 버튼 | 시작하기 / 오늘은 못 가요 | 둘 다 같은 크기. 거절도 대등한 선택 |

떠나는 곳: 시작하기 → 오늘 · 오늘은 못 가요 → 갈림길 B

## 2. 오늘

```
┌───────────────────────────────┐
│ 11월 27일 목요일                │  날짜 · 작게 · 회색
│ 오늘                           │  화면 이름
│ ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐ │
│   추운 날엔 실내 코스로 바꿀 수 ›  │  날씨 안내 · 조건부
│ └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘ │
│ ┌───────────────────────────┐ │
│ │ 오늘 할 운동                 │ │  오늘 할 운동 카드 (연한 초록)
│ │ 30분 헬스 코스               │ │  코스 이름 · 크게
│ │ 러닝머신 10분 → 하체 15분 → … │ │  순서 한 줄
│ │ (18:20) (헬스장) (30분)      │ │  칩 3개
│ │ ┌───────────────────────┐ │ │
│ │ │ 이런 이유로 추천드려요   │ │ │  추천 이유
│ │ │ · 최근 운동 시간(30~45분)에 맞췄어요     │
│ │ │ · 지난번에 상체를 했으니 오늘은 하체예요  │
│ │ │ · 가볍게 유산소로 몸을 데우면 더 수월해요 │
│ │ └───────────────────────┘ │ │
│ │ [       운동 시작        ]  │ │  주 버튼
│ │ 코스 자세히 보기  오늘은 못 가요│ │  보조 링크 2개
│ └───────────────────────────┘ │
│ ┌ 이번 주 지킨 운동 ──── 2 / 3회 ┐ │  요약 줄
│ ┌ 미룬 운동 ─────────── 1개 › ┐ │  요약 줄
├───────────────────────────────┤
│   오늘    기록    변화    나     │  탭바 · 오늘 활성
└───────────────────────────────┘
```

| 영역 | 들어가는 것 | 상태에 따른 변화 |
|---|---|---|
| 날씨 안내 | 실내 코스로 바꿀 수 있다는 한 줄 | 추운 날에만 보임. 바뀐 화면은 갈림길 A |
| 오늘 할 운동 카드 | 코스 이름, 동작 순서, 시간·장소·길이 칩 | 마감 2일 전이면 최소 계획 카드로 바뀜(갈림길 C) |
| 추천 이유 | 내 기록에서 나온 이유 3줄 | 이유는 항상 사용자 데이터(운동 시간, 지난 부위)에서 가져옴 |
| 이번 주 지킨 운동 | 지킨 횟수 / 약속한 횟수 | 운동 끝마다 갱신 |
| 미룬 운동 | 다음에 하기·아직 안 정함 상태의 약속 수 | 0개면 줄이 사라짐 |

로딩: 카드 자리에 뼈대 블록 + 「오늘 코스를 고르는 중…」 (상태 화면 · 로딩)
떠나는 곳: 운동 시작 → 운동 중 · 코스 자세히 보기 → 운동 코스 상세 · 오늘은 못 가요 → 갈림길 B

## 3. 운동 코스 상세

```
┌───────────────────────────────┐
│ ‹ 오늘                         │
│ 30분 헬스 코스                  │  화면 이름
│ (30분) (실내 가능) (강도 보통)    │  칩 3개
│ ┌───────────────────────────┐ │
│ │ ① 러닝머신 걷기   10분       │ │  동작 순서 목록
│ │ ② 레그프레스  12회×3세트·8분 │ │  번호 / 이름 / 양·시간
│ │ ③ 랫풀다운   12회×3세트·7분  │ │
│ │ ④ 스트레칭        5분        │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │      동작 예시 이미지 자리     │ │  이미지 자리
│ └───────────────────────────┘ │
│          다른 코스 보기          │  보조 링크
│                               │
│ [         운동 시작          ]  │  주 버튼 · 맨 아래
└───────────────────────────────┘
```

| 영역 | 들어가는 것 | 왜 |
|---|---|---|
| 칩 | 시간, 실내 가능 여부, 강도 | 운동 코스의 속성(예상 시간·실내 가능 여부·강도)을 그대로 보여 줌 |
| 동작 순서 | 번호, 동작 이름, 횟수·세트·시간 | 필라테스 수업처럼 "무엇을 어떤 순서로"가 정해져 있다는 느낌 |
| 다른 코스 보기 | 코스 목록으로 가는 유일한 길 | 코스 목록은 메뉴에 올리지 않음 |

추천 이유는 이 화면에 다시 넣지 않습니다. 오늘 화면에서 이미 봤기 때문입니다.
떠나는 곳: 운동 시작 → 운동 중 · 다른 코스 보기 → 코스 목록

## 4. 운동 중

```
┌───────────────────────────────┐
│ (✓ 출석 18:22)          2 / 4  │  출석 칩 · 진행 수
│ ████████████░░░░░░░░░░░░░░░░░ │  진행 바
│ ┌───────────────────────────┐ │
│ │        지금 할 동작          │ │  지금 동작 카드
│ │         레그프레스           │ │  크게
│ │        12회 × 3세트          │ │
│ └───────────────────────────┘ │
│           06:30 남음            │  남은 시간 · 가장 큰 숫자
│ ┌ 다음: 랫풀다운 7분 ───────────┐ │  다음 동작 미리보기
│                               │
│ [         다음 동작          ]  │  주 버튼
│          여기서 끝내기           │  보조 링크
└───────────────────────────────┘
```

| 영역 | 들어가는 것 | 상태에 따른 변화 |
|---|---|---|
| 출석 칩 | 운동 시작을 누른 시각 | 자동으로 남음. 사용자가 따로 체크하지 않음 |
| 지금 동작 카드 | 지금 할 동작 하나만 | 다음 동작을 누르면 바뀜 |
| 남은 시간 | 이 동작의 남은 시간 | 0이 되면 다음 동작으로 넘어가자고 안내 |
| 여기서 끝내기 | 중간에 끝내는 길 | 누르면 갈림길 D(바텀 시트) |

운동 중에는 탭바를 숨깁니다. 다른 메뉴로 새지 않게 하기 위해서입니다.
떠나는 곳: 마지막 동작 끝 → 운동 끝 · 여기서 끝내기 → 갈림길 D

## 5. 운동 끝

```
┌───────────────────────────────┐
│                               │
│            ( ✓ )              │  완료 표시
│         오늘 운동 끝!            │
│   28분 · 30분 헬스 코스 3/4 동작   │  한 일 요약
│ ┌───────────────────────────┐ │
│ │ 30분이 안 돼도 해낸 거예요.   │ │  인정 메시지
│ │ 기록에 남겼어요.              │ │
│ └───────────────────────────┘ │
│ ┌ 이번 주 지킨 운동 ──────── 3회 ┐ │
│                               │
│ [     좋아지는 흐름 보기      ]  │  주 버튼
│ [           닫기            ]  │  보조 버튼
└───────────────────────────────┘
```

| 영역 | 들어가는 것 | 상태에 따른 변화 |
|---|---|---|
| 한 일 요약 | 실제 운동 시간, 코스 이름, 한 동작 수 | 코스를 다 못 끝내도 「완료」로 기록 |
| 인정 메시지 | 해낸 것을 바로 인정하는 한 줄 | 30분 이상이면 「계획한 만큼 해냈어요」 |
| 이번 주 지킨 운동 | 갱신된 횟수 | 방금 운동이 반영된 값 |

오류: 저장에 실패해도 완료 표시는 그대로 두고, 인정 메시지 자리에 오류 안내를 얹음 (상태 화면 · 오류)
떠나는 곳: 좋아지는 흐름 보기 → 좋아지는 흐름 · 닫기 → 오늘

## 6. 좋아지는 흐름

```
┌───────────────────────────────┐
│ 변화                           │  화면 이름
│ (최근 4주) (최근 3개월)          │  기간 칩
│ ┌──────────┐ ┌──────────┐    │
│ │ 지킨 운동  │ │ 몸무게 흐름 │    │  요약 2칸
│ │ 16회      │ │ -0.4kg    │    │
│ └──────────┘ └──────────┘    │
│ ┌───────────────────────────┐ │
│ │   4주 흐름선 차트            │ │  차트
│ │   (튄 값은 흐리게)           │ │
│ └───────────────────────────┘ │
│ ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐ │
│   10/15: 어제 늦은 식사 때문일… │  이상치 안내 · 조건부
│ └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘ │
│ [         몸무게 재기         ]  │  보조 버튼
│ [     다음 운동 약속 정하기     ]  │  주 버튼
├───────────────────────────────┤
│   오늘    기록    변화    나     │  탭바 · 변화 활성
└───────────────────────────────┘
```

| 영역 | 들어가는 것 | 왜 |
|---|---|---|
| 요약 2칸 | 지킨 운동 횟수를 먼저, 몸무게 흐름을 다음 | 하루 몸무게보다 지킨 횟수와 흐름을 먼저 보여 준다는 원칙 |
| 차트 | 4주 흐름선 | 하루 값이 아니라 추세를 봄 |
| 이상치 안내 | 튄 날짜와 그럴 만한 이유 | 경고가 아니라 설명. 튄 값이 없으면 사라짐 |
| 다음 운동 약속 | 이 화면의 주 버튼 | 흐름을 본 직후가 다음 약속을 정하기 좋은 때 |

빈 상태: 기록이 2개 미만이면 차트 자리에 「두 번 더 재면 흐름이 보여요」
떠나는 곳: 다음 운동 약속 정하기 → 운동 약속 정하기 · 몸무게 재기 → 몸무게 기록

## 7. 운동 약속 정하기

```
┌───────────────────────────────┐
│ ‹ 변화                         │
│ 다음 운동 약속                  │  화면 이름
│ 날짜                           │
│ (토 11/29)(월 12/1)(화 12/2)(목 12/4)│  날짜 칩 · 하나 선택
│ 시간                           │
│ ┌ 18:20 (독서실 퇴실 후) ── 바꾸기 ┐ │
│ 코스                           │
│ ┌ 30분 헬스 코스 ──────── 바꾸기 ┐ │
│ ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐ │
│   12/3 지원 마감 이틀 전이에요…   │  마감 안내 · 조건부
│ └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘ │
│                               │
│ [         약속 정하기         ]  │  주 버튼
│        아직 안 정함으로 두기      │  보조 링크
└───────────────────────────────┘
```

| 영역 | 들어가는 것 | 상태에 따른 변화 |
|---|---|---|
| 날짜 칩 | 앞으로 일주일 안의 날짜 4개 | 가장 가까운 날이 미리 선택됨 |
| 시간 | 독서실 퇴실 시각 기준 기본값 | 바꾸기로 고칠 수 있음 |
| 코스 | 지난번 코스를 기본으로 | 마감이 가까우면 가벼운 코스를 추천 |
| 아직 안 정함 | 약속을 미루는 길 | 탓하지 않음. 오늘 화면 「미룬 운동」에 남음 |

떠나는 곳: 약속 정하기 → 오늘 · 아직 안 정함으로 두기 → 오늘

## 갈림길

### A. [추운 날] 오늘 → 실내 코스

```
┌───────────────────────────────┐
│ 오늘                           │
│ ┌───────────────────────────┐ │
│ │ 오늘은 -3°C예요.             │ │  날씨 배너 (실선 · 연한 초록)
│ │ 집에서 하는 실내 코스로 바꿨어요│ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 20분 실내 코스               │ │
│ │ 제자리 걷기 → 스쿼트·런지 → … │ │
│ │ (집) (20분) (도구 없음)       │ │
│ │ 이런 이유로 추천드려요          │ │
│ │ · 추운 날엔 밖에 나가기가 특히 어려웠어요 │
│ │ · 집에서 바로 할 수 있는 동작만 골랐어요  │
│ │ · 지난번에 상체를 했으니 오늘은 하체예요  │
│ │ [       운동 시작        ]  │ │
│ │     헬스장 코스로 되돌리기      │ │  되돌리는 길
│ └───────────────────────────┘ │
└───────────────────────────────┘
```

근거: 한파 주간(10/19~25) 헬스·걷기 0회 (workout.csv). 화면을 바꾸지 않고 오늘 카드의 내용만 바뀝니다.

### B. [오늘은 못 가요] → 가벼운 10분 제안

```
┌───────────────────────────────┐
│ ‹ 오늘                         │
```

## 레이아웃을 정할 때 지킨 것

1. **오늘 할 운동은 하나만.** 고르는 순간 망설임이 생깁니다(여정 ①). 다른 코스는 「다른 코스 보기」 뒤로 숨깁니다.
2. **추천에는 이유를 붙입니다.** 「이런 이유로 추천드려요」로 내 기록에서 나온 근거를 보여 줘야 정해 준 코스를 믿고 바로 시작합니다. 같은 이유를 두 번 보여 주지 않도록 오늘 화면에만 둡니다.
3. **빠져나가는 길도 대등하게.** 「오늘은 못 가요」「여기서 끝내기」「아직 안 정함으로 두기」는 언제나 보이고, 누른 뒤에도 실패로 남지 않습니다.
4. **상태는 화면 위에 얹습니다.** 추운 날, 마감, 이상치, 오류는 기존 화면의 카드나 배너를 바꾸는 방식이라 하던 일이 끊기지 않습니다. 중간에 끝내기만 바텀 시트로 띄웁니다.
5. **하루 숫자보다 흐름과 횟수.** 변화 화면은 지킨 운동 횟수를 먼저, 몸무게는 흐름으로 보여 줍니다. 빨간색과 느낌표는 쓰지 않습니다.
