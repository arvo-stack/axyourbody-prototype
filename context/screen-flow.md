# AX YOUR BODY — 과업별 화면 흐름 순서표와 화면 목록

## 핵심 과업
과업 3 · 헬스에 혼자 가야 하는 날, 필라테스 수업처럼 정해진 시간과 메뉴를 받고 싶다. 그래서 고민 없이 바로 시작하고 싶다.

## 기본 흐름
퇴실 알림 → 오늘 → 운동 코스 상세 → 운동 중 → 운동 끝 → 좋아지는 흐름 → 운동 약속 정하기

## 갈림길
- [추운 날] 오늘 → 실내 코스로 바뀐 오늘 → 운동 중
- [오늘은 못 가요] 오늘 → 가벼운 10분 제안 하나 → 운동 약속 정하기
- [지원 마감 2일 전 이내] 오늘 → 최소 계획(필라테스만, 수면 우선) → 운동 약속 정하기
- [코스 중간에 끝내기] 운동 중 → 운동 끝 (30분 미만도 완료 인정)

## 화면 목록

| 화면 이름 | 이 화면의 목적 | 측정 지표 1개 |
|---|---|---|
| 퇴실 알림 | 독서실 퇴실 시각에 오늘 할 운동 하나를 알려 출발을 돕는다 | 알림을 눌러 오늘 화면을 연 비율 |
| 오늘 | 오늘 할 운동과 코스를 하나만 정해서 보여 준다 | 오늘 화면에서 '운동 시작'을 누른 비율 |
| 운동 코스 상세 | 순서와 시간을 미리 보여 줘 "뭘 하지?" 고민을 없앤다 | 상세에서 운동 시작으로 넘어간 비율 |
| 운동 중 | 다음 동작을 하나씩 안내하고, 출석은 자동으로 남긴다 | 코스 완주율 |
| 운동 끝 | 해낸 것을 바로 인정하고 운동 기록을 저장한다 | 운동 기록 저장률 |
| 좋아지는 흐름 | 하루 몸무게 대신 4주 흐름과 지킨 횟수를 보여 준다 | 흐름을 본 뒤 다음 약속까지 정한 비율 |
| 운동 약속 정하기 | 다음 헬스 날짜와 코스를 미리 정해 공백을 막는다 | 헬스 사이 간격 (지금 최장 13일 → 7일 이하) |

## 상태 화면 목록

| 상태 | 어느 화면 | 근거 데이터 | 보여 줄 것 |
|---|---|---|---|
| 빈 상태 | 기록 › 식사 · 좋아지는 흐름 | 10/23~25 저녁 기록, 10/23~24 수면 기록 누락 (meal.csv, sleep.csv) | "비어 있어도 괜찮아요. 오늘 하나만 남겨요" + 기록 버튼 하나 · 탓하는 표시 없음 |
| 오류 | 운동 끝 | (일반 상황) 운동 기록 저장 실패 | "기록은 이 기기에 남겨 뒀어요. 연결되면 저장돼요" + 다시 시도 |
| 로딩 | 오늘 | (일반 상황) 날씨와 오늘 코스를 불러오는 중 | 코스 카드 자리에 뼈대 화면 + "오늘 코스를 고르는 중" |
| 이상치 | 좋아지는 흐름 | 10/15 몸무게 +0.9kg, 전날 야식 (body.csv) | 튄 값은 흐리게 표시 + "어제 늦은 식사 때문일 수 있어요. 흐름에는 작게 반영해요" |
