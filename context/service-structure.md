# AX YOUR BODY — 서비스 구조 설명서 (가상 프로필 my-general · 직접 만든 일반인 남성 프로필)

## 1. 서비스와 사용자
- 서비스: 혼자 하는 운동을 수업처럼 정해 주고, 운동·식사·몸무게 기록을 모아 '좋아지는 흐름'을 한눈에 보여 주는 개인 운동·식단·건강 관리 앱.
- 사용자: 정해진 수업(필라테스)은 꾸준히 가지만 혼자 하는 헬스는 자주 놓치고, 지원 마감·결과 발표에 따라 컨디션이 크게 흔들리는 30대 취업 준비생. 운동 지출은 최소로 하고 싶어 함.
- 가장 중요한 과업 (과업 3): 헬스에 혼자 가야 하는 날, 필라테스 수업처럼 정해진 시간과 메뉴를 받아 고민 없이 바로 시작한다.

## 2. 대상 객체와 핵심 속성
- 사용자: 프로필 ID, 목표 체중, 목표 기한 (선택: 키, 독서실 종료 시각)
- 운동 계획: 날짜, 예정 시각, 장소(헬스장·실내·필라테스), 상태(예정·보류·완료·미정) (선택: 보류 사유, 날씨 조건)
- 운동 메뉴: 메뉴 이름, 예상 시간(분), 운동 항목 순서 (선택: 강도, 실내 가능 여부)
- 운동 세션: 날짜, 종류(헬스·필라테스·걷기), 시작 시각, 종료 시각 (선택: 체크인 시각, 걸음 수, 활동 메모)
- 식사: 날짜, 끼니(아침·점심·간식·저녁·야식), 탄수화물(g), 단백질(g), 지방(g) (선택: 먹은 시각)
- 체중 측정: 측정일, 체중(kg), 측정 조건 (선택: 골격근량(kg), 체지방률(%), 메모)
- 계산되는 값은 저장하지 않고 화면에서 계산한다: 운동 시간(분), 열량 합계, 지난 측정과의 차이, 체중 추세.

## 3. 관계
- 사용자 1:N 운동 계획
- 사용자 1:N 운동 세션
- 사용자 1:N 식사
- 사용자 1:N 체중 측정
- 운동 메뉴 1:N 운동 계획 (계획에 메뉴가 없을 수 있음)
- 운동 메뉴 1:N 운동 세션 (세션에 메뉴가 없을 수 있음)
- 운동 계획 1:1 운동 세션 (양쪽 모두 선택: 보류된 계획은 세션이 없고, 계획 없이 한 걷기는 세션만 있음)
- 식사·체중 측정은 운동과 직접 잇지 않고 날짜로 나란히 놓아 비교한다.

## 4. 사건
날씨가 확인됨 → 오늘 운동 계획이 보류됨 → 귀가 경로가 집 쪽으로 정해짐 → 저녁 식사가 기록됨 → 헬스장 출석이 체크됨 → 운동 세션이 시작됨 → 운동 메뉴가 즉석에서 정해짐 → 운동 세션이 30분 만에 종료됨 → 운동 기록이 저장됨 → 체중이 측정됨 → 지난 체중과 비교됨 → 다음 운동 계획이 미정으로 남음

## 5. 화면에 쓸 말
- 사용자 = "나", "내 정보"
- 운동 계획 = "오늘 할 운동" (오늘) · "운동 약속" (다음 날짜)
- 계획 상태 보류 = "다음에 하기" · 미정 = "아직 안 정함"
- 운동 메뉴 = "운동 코스" (예: "30분 헬스 코스")
- 운동 세션 = "운동" (하는 중: 운동 시작, 운동 끝) · "운동 기록" (저장된 뒤 목록)
- 체크인 시각 = "출석"
- 식사 = "식사" · 끼니 = "아침, 점심, 간식, 저녁, 야식" · 영양소 = "탄수화물·단백질·지방"
- 체중 측정 = "몸무게" (기록 화면: "몸무게 재기", 값 하나: "오늘 몸무게")
- 체중 추세 = "좋아지는 흐름"
- 날씨 조건 = "추운 날", "실내 코스"
- 피할 말: 회원, 고객, 플랜, 스케줄, 목표(운동 계획에 쓸 때), 실패, 미완료, 건너뜀, 프로그램, 템플릿, 세트(코스 뜻으로), 세션, 워크아웃, 체크인, 로그인, 폭식, 치팅, 섭취량, 탄단지, 감량 실패, 증가 경고, 통계, 그래프 데이터, 변동, 기상 정보, 외부 환경

## 6. 메뉴와 위치 표시
- 메뉴 4개, 하단 탭, 이 순서로: 1) 오늘 2) 기록 3) 변화 4) 나
  - 오늘: 오늘 할 운동과 코스 하나를 정해서 보여 줌 (과업 3·4·5의 시작점)
  - 기록: 운동 기록과 식사 기록 (위쪽 구분 탭: 운동 · 식사)
  - 변화: 몸무게 재기와 좋아지는 흐름 (보는 기간 표시, 예: 최근 4주)
  - 나: 목표 몸무게, 지원 마감일 등록 (하위: 일정)
- 위치 표시: 하단 탭에서 지금 메뉴를 강조한다. 오늘 화면은 맨 위에 날짜 제목, 기록 화면은 구분 탭 강조, 변화 화면은 제목 옆에 보는 기간, 나의 하위 화면은 제목 위에 "나 › 일정"처럼 경로를 표시한다.
- 메뉴에 올리지 않은 것과 찾는 곳:
  - 운동 코스 목록 → 오늘 화면의 "다른 코스 보기"
  - 다음에 하기·아직 안 정함 상태의 운동 약속 → 오늘 화면 아래 "미룬 운동" 묶음, 기록 › 운동 목록의 상태 표시
  - 날씨 → 추운 날에만 오늘 화면 맨 위 안내로 나타남
  - 출석 → 운동 시작을 누르면 자동으로 남고, 운동 기록 상세에서 확인
  - 지원 마감일 → 나 › 일정

## 7. 검색·필터
- 운동 기록: 날짜(기간), 종류(헬스·필라테스·걷기)
- 운동 약속: 상태(예정·다음에 하기·아직 안 정함), 장소
- 운동 코스: 예상 시간(분), 실내 가능 여부, 강도
- 식사: 날짜, 끼니(아침·점심·간식·저녁·야식)
- 몸무게: 측정일(기간), 측정 조건

## 8. 하지 말 것
- 오늘 화면에서 운동 코스를 여러 개 나열해 고르게 하지 않는다. 오늘 할 운동은 하나만 정해서 보여 준다.
- 운동을 미루거나 기록이 빈 날을 실패·경고·빨간색으로 표시하지 않는다.
- 하루 몸무게 숫자를 가장 크게 보여 주지 않는다. 좋아지는 흐름과 지킨 횟수를 먼저 보여 준다.
- 야식이나 많이 먹은 날을 탓하거나 평가하는 문구를 쓰지 않는다.
- 유료 PT, 구독, 결제 유도 화면을 만들지 않는다.
- 컨디션이 낮은 날 선택지를 여러 개 주지 않는다. 가벼운 제안 하나만 준다.
- 메뉴를 4개보다 늘리지 않고, 메뉴 이름을 5장의 사용자 용어와 다르게 쓰지 않는다.
- 2장에 없는 대상 객체나 속성을 새로 만들지 않는다.
- 실제 이름·연락처·실제 신체 수치를 넣지 않는다. 화면의 사용자는 가상 프로필 ID(my-general)로만 표시한다.
